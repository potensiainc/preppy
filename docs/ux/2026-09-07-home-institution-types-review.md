## 검증 범위

- 로컬 실제 Next.js와 격리된 PostgreSQL 테스트 DB 사용. 운영 데이터에 합성 기관을 넣지 않음.
- 관련 단위 테스트 24개, 홈/아티클 조회 통합 테스트 6개 통과.
- TypeScript 검사, 변경 파일 ESLint, 프로덕션 빌드 통과.
- Chromium 및 WebKit의 네 화면 너비에서 세 유형의 구역 배치와 영어유치원·사립초등학교의 구역 → 기관 상세 → 뒤로가기 → 유형별 전체 목록 동선 통과. 국제학교의 전체 목록 링크는 단위 검사로 확인했으며, 로컬 초기 브라우저 검사에서는 클릭하지 않았다. 최종 검사 스크립트는 존재하는 모든 유형의 전체 목록 링크를 순회하도록 보완했다.
- JavaScript를 끈 상태에서도 두 주요 유형 구역과 기관 링크 제공.
- 브라우저 실행 오류, 가로 넘침, 제목의 고정 헤더 가림 검사 통과.
- 이는 브라우저 자동화와 에이전트의 화면 검수다. 실제 학부모 사용성 조사나 실물 iPhone/Android 기기 검증을 수행했다고 주장하지 않는다.
- 재현: `python tests/browser/run-home-institution-types.py --base-url <대상 URL>`; WebKit은 `--engine webkit` 추가.

### WebKit 진단 중 관찰한 제한

초기 검사는 전체 목록 방문 사이에 `page.goto`로 홈을 강제로 다시 열었다. 이 흐름에서 WebKit의 일부 `_rsc` 사전 로딩 요청에 접근 검사 오류가 간헐적으로 기록됐고, 같은 이동 단계에 요청 취소도 기록됐다. 원인이 CORS 정책 문제인지 브라우저의 탐색 취소 처리인지 확정하지 않았다. 해당 오류를 제품 코드에서 수정했다고 주장하지 않는다.

학부모의 실제 행동을 검증하도록 유형 이동 링크와 뒤로가기를 사용하는 동선으로 보완했다. **오류 무시나 필터링은 추가하지 않았으며**, 보완 후 두 엔진의 네 화면 너비와 JavaScript 비활성 검사가 모두 통과했다. 최종 통과 범위는 이 실제 링크 동선이며, 강제 페이지 이동 상황의 간헐 오류까지 해결됐다는 의미는 아니다. 향후 실물 Safari 검수 시 빠른 페이지 이동·새로고침을 함께 확인한다.

문구를 짧게 보완한 `a1ed6ae`의 최종 WebKit 재검사는 자동화 브라우저의 첫 페이지 생성 단계에서 응답 없이 대기했다. 단계 기록을 추가한 단일 320px 재실행에서도 최초 사이트 접속 전 대기해 검사 프로세스를 중단했다. 같은 검사 코드는 Chromium 320px에서 즉시 통과했다. **최종 코드의 WebKit 재검사는 미완료**이며, 위 표의 WebKit 통과는 직전 코드 `cc183af`의 결과다. 브라우저 시작 대기의 원인은 확정하지 않았고, 이를 서비스 UI 오류 또는 폰트 오류로 단정하지 않는다. 검사 스크립트에는 추후 진단을 위한 `--trace`와 폰트 로딩 15초 제한을 추가했다.

## UX Writing: PASS — 구현·로컬·운영 탐색 검수 범위

- 대상: 홈 구역 제목·설명·이동 링크, 공용 기관 카드 지역명.
- 기존 ‘각 기관의 기본 정보와 확인된 입학정보를 살펴볼 수 있어요.’를 ‘기관 유형별로 나누어 살펴보세요.’로 변경했다. 최종 리뷰에서 추가 기관이 반드시 존재한다고 약속하는 ‘더 많은 기관’ 문장을 제거해 빈 상태·소수 기관 상태에서도 사실을 보존한다. 유형별 전체 보기 링크는 유지한다.
- 제목은 ‘영어유치원’, ‘사립초등학교’, ‘국제학교’, 링크는 ‘[유형] 전체 보기’로 실제 도착 화면과 일치한다.
- 입학정보 제목·학년도·일정 링크·내용 확인 시각은 기존 자료를 유지한다. 단위 테스트에서 학년도, 상세 링크, 확인 시각 보존을 대조했다.
- 등록되지 않은 유형에 가짜 기관이나 ‘준비 중’ 구역을 만들지 않는다. 모든 유형에 공개 기관이 없는 경우 기존 빈 상태 안내를 유지한다.
- 검수 기준: `docs/PREPPY_UX_WRITING_POLICY.md` 전체 적용. 폰트와 초록색 계열의 기존 PREPPY 디자인을 유지하며 구조와 간격을 보완했다.

## 배포 경로 검증 절차

이 작업의 릴리스 폴더는 `D:\potensia\preppy\.worktrees\english-kindergarten-mvp`다. 원래 프로젝트 폴더와 서로 다른 체크아웃이므로, 셸의 작업 폴더만 지정한 `railway up`에 의존하지 않는다. 명시적인 업로드 루트와 운영 서비스·환경을 함께 지정한다.

## 재방문 개선을 위한 다음 검증 과제

이번 작업으로 해결한 것은 유형 구분과 탐색 동선이다. 재방문율·인지도 상승은 아직 측정하지 않았다.

1. 원비·연령·셔틀·입학설명회에서 미확인 정보의 비율과 공식 자료 확보 가능성을 확인해 데이터 보강 순서를 정한다. 사용자의 질문에 답하는 정보가 재방문 경험의 기반이다.
2. 실제 보호자가 ‘내 지역 영어유치원 찾기’, ‘사립초 입학 일정 확인’, ‘관심기관 다시 찾기’를 수행하는지 조사한다. 성공 여부, 막힌 지점, 이해하지 못한 문구를 기록한다.
3. 유형별 전체 목록 진입, 기관 상세 열람, 관심기관 등록 이후 재방문을 측정해 효과를 판단한다. 이번 변경에 새 추적 코드나 개인정보 수집은 추가하지 않았다.
