## 출처 및 캡처의 의미

각 출처의 `evidenceText`는 검토된 문단과 여전히 유효한 사실·일정 발췌를 사용해
새로 만들었다. 이전 자유서술 증거를 통째로 복사하지 않았다. 운영자 사실 요약임을
명시하고, 본 모집 안내와 다른 학년도의 별도 게시물을 출처 텍스트 안에서도 분리한다.

HTTP 출처는 실제 취득시각·상태·바이트 수·소요시간·원본 응답 SHA-256을 사용한다.
모든 HTTP 응답은 2 MiB 이하이며 로컬 원본 파일의 해시·바이트 수를 조립 시 다시
확인했다. 새 검토시각으로 과거 취득시각을 바꾸지 않았다.

브라우저 출처 6건은 HTTP 상태·응답 바이트·소요시간을 null로 유지한다. 이 경우
`responseContentHash`는 실제 로컬 화면·본문 캡처 또는 캡처 묶음 파일의 해시이며
원본 서버 응답·원본 PDF 해시를 뜻하지 않는다.
