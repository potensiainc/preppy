# 아티클 작성 가이드

## 가장 빠른 방법: Claude로 초안 작성 → HTML 붙여넣기

1. Admin → 아티클 → 새 아티클에서 주소 이름(slug)과 제목을 넣고 초안을 만들어요.
2. 아래 프롬프트로 Claude에게 본문 HTML을 받아요.
3. 편집 화면의 **HTML 편집**에 붙여넣기 → **화면 편집**으로 돌아와 확인해요.
4. 요약(또는 검색 설명)을 채우고 연결할 기관·입학정보를 검색해 체크해요.
5. `Ctrl+S`로 초안을 저장하고, 미리보기를 확인한 뒤 **아티클 발행**을 눌러요.

### 프롬프트 템플릿

```text
프레피(영유·사립초·국제학교 입학정보 서비스) 아티클 본문을 HTML로 써줘.
주제: <예: 2027학년도 서울 사립초 원서접수 일정 총정리>
독자: 3~8세 자녀를 둔 부모
규칙:
- 사용 가능한 태그만 써: h2, h3, h4, p, strong, em, ul, ol, li, blockquote, a, hr, table, thead, tbody, tr, th, td, img
- h1, div, span, style, class 속성은 쓰지 마
- 표는 <table><thead><tr><th>…</th></tr></thead><tbody>…</tbody></table> 형태
- 이미지는 https:// 주소만, alt 필수
- 해요체, 날짜·금액·대상은 공식 출처 그대로, 미확정 정보는 "예정"이라고 표시
- 마지막에 "신청 전 학교 공식 안내를 꼭 확인해 주세요." 문단 추가
- 코드블록 하나로 HTML만 출력
자료: <공식 요강 링크나 내용을 붙여넣기>
```

## 태그와 공유 이미지

- 태그는 쉼표로 구분해 최대 10개예요. 태그마다 `/articles/tag/태그` 모아보기 페이지가 생기고, 글이 2개 이상 모이면 검색에 노출돼요.
- 태그는 검색어처럼 써요: `강남 영유`, `사립초 추첨`, `국제학교 입학 자격`. 같은 뜻은 한 가지 표현으로 통일해요.
- 공유 이미지는 자동으로 1200×630으로 만들어져요. 대표 이미지가 있으면 잘리지 않게 가운데에 넣고, 없으면 제목 카드를 만들어요.
- 대표 이미지는 가로형(1.91:1)이 가장 크게 보여요. 세로형도 잘리지 않지만 작게 보여요.

## 발행 조건

- 본문 공백 제외 40자 이상
- 요약 또는 검색 설명 중 하나 이상
- 대표 URL은 비워 두기 (자동으로 이 글 주소가 돼요)
- 연결은 기관·입학정보 각각 최대 12개

## 글자 수 기준

| 항목 | 최대 | 권장 |
|---|---|---|
| 제목 | 160자 | 30~40자 |
| 검색 제목 | 70자 | 30~35자 (비우면 제목 사용) |
| 검색 설명 | 320자 | 80~120자 |
| 요약 | 500자 | 1~2문장 |

## 이미지

본문 이미지는 https:// 주소로만 넣을 수 있어요. 파일 업로드는 아직 없으니 이미지 호스팅(예: 공개 버킷, 블로그 이미지 주소)을 써 주세요. 학교 요강 캡처는 저작권과 개인정보가 없는지 확인해요.
