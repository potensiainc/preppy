# PREPPY 서울 사립초 38개교 통학 공개자료 조사

수집·검토일: 2026-10-15 · 시각 기준: 한국 표준시(Asia/Seoul)

38개교의 공개 통학 자료를 출처별로 기록한 조사 묶음입니다. 현재 실제 운행, 좌석, 신입생 승차 자격, 2027학년도 운행을 보증하는 데이터는 아닙니다. 전체 학교의 정류장·시간표를 완성한 결과도 아닙니다.

## 범위와 정확한 수량

- 학교 감사 기록: 38개교, 기존 38개교 목록과 ID가 정확히 일치
- 출처: 163개 기록, 서로 다른 URL 151개. 같은 URL이라도 학교·해석 맥락이 달라 별도 기록될 수 있음
- 필드·문장 단위 사실: 143개. 사실 수는 정류장 수가 아님
- 상세 노선 기록: 81개, 정류장 표의 행 709개
  - 경복: 방향별 기록 28개 / 표 행 121개
  - 계성: 노선 페이지 10개 / 표 행 82개
  - 명지: 방향·요일·회차별 기록 43개 / 표 행 506개
- 출처 상태: 공식 원문을 읽음 33개, 오래되거나 대체된 공식 자료 8개, 미검증 2차 자료 64개, 접근·판독 불가 58개
- 학교별 자료 범위: 게시 시간표 원문 4곳, 조달 계획 원문 8곳, 공지만 확인하고 노선은 읽지 못한 곳 1곳, 과거 공식 참고자료 4곳, 주요 원문 접근 불가 20곳, 현행 통학 문서를 찾지 못한 곳 1곳
- 실제 현재 운행을 검증한 학교: 0곳. 2027학년도 시간표를 검증한 학교: 0곳

위 분류는 자료의 읽기·확인 범위를 뜻합니다. 차량 대수, 번호가 다른 노선 수, 방향·요일·회차별 기록 수, 고유 정류장 수를 서로 바꿔 쓰면 안 됩니다. 709행에는 학교 도착·출발, 복귀 지점, 다른 노선 참조와 반복 정류장이 포함됩니다. 영훈·태강 등의 선택 추출은 facts 파일에 따로 있으므로 709행에 합산하지 않았습니다.

## 파일

- `research.json`: 메타데이터, 38개교, 출처, 사실, 상세 노선과 주의사항을 모두 담은 기준 파일
- `schools.json` / `schools.csv`: 학교별 감사 결과와 자료 범위
- `sources.json` / `sources.csv`: 정확한 URL, 제목, 출처 유형, 접근 결과, 날짜와 학년도
- `facts.json` / `facts.csv`: 필드·문장별 값, 출처 ID, 원문 위치, 증거 유형과 사용 제한
- `routes.json`: 경복·계성·명지의 상세 노선 및 표 행. 원문 시각 표기와 시각 종류를 보존
- `route-stops.csv`: 위 상세 노선의 표 행 709개를 펼친 파일
- `validation.json`: 수량, ID 연결, 학교 범위, 개인정보 패턴 및 금지된 해석 검사 결과
- `manifest.json`: 파일별 바이트 크기와 SHA-256 무결성 해시

CSV는 UTF-8 BOM 형식이며 첫 행이 열 이름입니다. 배열·객체는 한 셀 안에 JSON으로 저장했습니다. 빈 값은 미확인·미기재이며 0이나 “없음”을 뜻하지 않습니다. 정밀한 상태·주의사항은 JSON을 기준으로 확인하세요.

## 반드시 유지할 구분

`official_verified`는 공식 문서에 적힌 내용을 직접 읽었다는 뜻입니다. 실제 현재 운행 여부는 별도이며 이 묶음에서는 모두 미확인입니다. 공식 조달 문서를 읽었다고 낙찰·계약 이행·현재 운행이 확인되는 것은 아닙니다.

- `official_older`: 과거 학년도, 대체된 문서, 현행 게시물과 다른 공식 자료
- `secondary_unverified`: 공개 블로그·기사·조달 목록 등의 미검증 주장 또는 단서
- `inaccessible`: 링크는 찾았으나 보안 필터, 접근 제한, 파일 형식 등으로 읽지 못함
- `not_found`: 제한된 검색 범위에서 관련 문서를 찾지 못함

게시일, 학년도, 첨부파일 개정일, 조회일, 시행일은 다른 값입니다. 조회일이 최근이라는 이유로 현행 운행으로 승격하면 안 됩니다. 2026학년도 계약의 2027년 2월 종료는 2027학년도 운행표가 아닙니다.

## 지도·서비스 반영 권고

1. 38개교의 조사 상태, 원문 링크, 확인일, 제한사항을 자료 안내 영역에 반영할 수 있습니다.
2. 게시 원문과 공식 계획, 과거 참고자료, 미검증 2차 자료를 별도로 표시하세요. 모든 값에 source_ids와 evidence_kind 또는 동등한 출처 정보를 유지하세요.
3. 현재 운행 데이터의 자동 덮어쓰기는 권하지 않습니다. 학교별 적용 학년도와 최신 개정, 요일·회차·학년·신입생 제한을 추가 확인한 후 반영해야 합니다.
4. `quarantined_quality_issue`와 `quarantined_date_inference`는 실제 운행 필드에 가져오지 마세요. `comparison_only`, `historical_reference_only`, `unverified_lead_only`, `source_metadata_only`도 현행 확정 사실로 가져오면 안 됩니다.
5. 등교 정류장을 거꾸로 나열해 하교를 만들거나, 출발 시각 차이를 모든 정류장에 일괄 적용하면 안 됩니다. 사는 곳부터 학교까지의 예상 통학시간, 입학 자격, 좌석 확보 여부를 계산·보장할 근거가 없습니다.
6. 확인 실패는 “버스 없음”이 아닙니다. 운현의 미운행 주장도 공식 확인 전에는 2차 자료로 유지하세요.

공개 학교 페이지, 공개 첨부와 조달 문서, 검색·공개 블로그·기사의 범위 안에서 조사했습니다. 학교 보안 필터와 Naver 접근 제한 등을 우회하지 않았습니다. 모든 커뮤니티나 모든 개정 문서를 확인한 것은 아닙니다. 통합 검토는 수집 기록과 연결 관계를 검사한 것으로, 모든 URL을 다시 조회한 검사는 아닙니다.
